# Claude Check Tool

A small utility for testing Claude Code's repository summarization capabilities.

## Setup

1. Clone this repository.
2. Run the following command from inside the repository folder:

       claude -p "summarize this repository md"

3. If Claude successfully summarizes the Markdown file, the setup works correctly.

## What It Tests

This tool verifies that Claude Code can:

- Read and summarize local Markdown files
- Operate correctly inside a fresh repository session

- History_Of_Dragons.md — A sample Markdown file for summarization testing.
